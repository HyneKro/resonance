# Importing online playlists

Resonance reads playlist links without signing into your music account. Spotify and Deezer playlists must be public; YouTube and YouTube Music playlists can be public or unlisted. Private playlists that require an account are not supported.

In Spotify, open the playlist’s **⋯ → Make public**, then check it again in Resonance. Removing a playlist from your profile is a separate setting: it does not make the playlist private. See [Spotify’s privacy guide](https://support.spotify.com/article/playlist-privacy-and-access/).

Use the full `open.spotify.com/playlist/…` or `deezer.com/playlist/…` link. Spotify’s anonymous page can expose only the first 100 tracks. A public playlist can also fail because of a temporary service or connection problem; an access error is not proof that it is private.

Spotify and Deezer supply song information, not downloadable audio. Windows and Android automatically search for YouTube recordings when checking the playlist. Proposed recordings remain unchecked: compare the artist, version and duration, then select the songs you want and use **Download**. Android’s **Review recording** and Windows’ **Review** let you inspect alternatives. If no recording was found, use **Choose recording** or the selection box to search again.

Checking playlists again preserves chosen recordings on Android, even when playlist order changes. Nothing downloads merely because you paste a link or choose a recording.

Disconnecting a source on Android removes its pending and skipped songs, including from a running batch. Other connected playlists can continue downloading. Finished music is kept. Old pending entries for sources that are no longer connected are cleared when the download list is restored.
