# Free Flux orbit and a smoother Afterglow drive

Development test builds: Windows **1.26.0-dev.32** and Android **0.26.0-dev.32** (versionCode 98).

- **Flux:** removed angle-dependent automatic framing. Dragging now rotates freely at a fixed orbit radius instead of moving the camera closer/farther at each angle. Explore zoom and Fit view remain explicit controls; scrolling remains dedicated to volume. Some views may deliberately crop the field when orbiting closely.
- **Afterglow particles:** smaller instanced pixel tiles lie parallel to the road. Their trails follow road depth without the previous sideways offset. Musical brightness and bounded phone populations remain.
- **Afterglow palms:** fixed the silhouette variant changing across a tree's triangles due to interpolated IDs crossing atlas boundaries. Flat tree identities, mipmapped filtering, explicit texture gradients and soft coverage stabilize thin leaves. Palms draw from far to near, with smooth distance fades and stable identities as they pass.
- **Afterglow skyline:** added penthouses, twin towers, terraces, balconies, side-face shading, facade ribs and window frames. The spectral window wave remains, with a softer echo and illuminated rows beneath it.
- **Afterglow continuity:** a persistent motion state retains road position, city/window phase, palette and terrain history when skipping songs. Frequencies, lighting and roles ease toward new targets; pause coasts into a slow ambient drift and play accelerates smoothly. Freeze and reduced motion still hold the scene, and hidden/inactive gaps do not cause catch-up jumps.
- **Noctiluca removed:** the menu and dedicated controls/defaults are gone on both platforms. Saved or imported Noctiluca selections fall back to Resonance. Removed its fish simulation, dedicated shaders, GPU allocations and unused legacy scenic shader module from both distributions. Remaining scene indices stay stable.

Verification: **547 shared tests** and **134 Android JVM tests** passed. Both Android ABIs built; lint reports zero errors and nine existing warnings. All **seven** remaining directions passed GPU output, independent musical-role and graphics-context recovery checks. Dedicated Flux checks cover free camera angles, exploration, volume/zoom isolation and continuity. Afterglow checks cover actual road-parallel particle geometry, straight trails, consecutive-frame palm brightness, skyline windows, CRT bypass, retained history and smooth pause/play/skip/palette transitions. Windows and Android UI checks confirm seven visual choices with Noctiluca absent. Both extracted startup module graphs pass; removed modules are absent in both artifacts and unavailable through the Windows server. Shared modified visual modules match both distributions byte-for-byte. A clean Windows installation reaches the empty-library welcome screen in approximately **9.8 seconds**. Android retains package `music.resonance.mobile` and its existing signing certificate. No physical Android device testing was available.

Use **Settings → App updates → Check for updates** in an existing development installation. Windows applies the update on your restart action. Android updates the existing app with system confirmation; do not uninstall. First-time development users need the one-time development ZIP/APK installation. Ordinary releases and the live download buttons remain unchanged.
