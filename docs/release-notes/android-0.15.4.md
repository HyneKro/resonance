# Resonance Android 0.15.4 preview · Companion release

Companion build for the Windows notification-area feature. Android retains its existing playback notification and background controls; the Windows tray integration does not change phone behavior.

Validation: all 334 JavaScript tests and 110 native JVM tests pass. Both ABI builds and the instrumented-test APK compile. Android lint reports no errors and nine existing warnings; the extracted APK's complete startup module graph passes. No physical Android device was available for this release.

ARM64 preview, versionCode 37, unchanged package ID and signing certificate. Install over the existing app to retain music, playlists and settings.
