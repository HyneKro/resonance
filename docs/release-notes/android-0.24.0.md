# Resonance Android 0.24.0-preview

Music only now shares the new listening edition: cover-inspired colors, layered artwork, expressive typography and four music-style treatments. Album details appear when available, and Behind the sound is easy to reach.

Phone layouts fit around the existing playback controls. Short screens use a compact composition; landscape and long titles are handled without pushing the player off-screen. Missing artwork gets a clean fallback. This mode adds no continuous rendering, background recognition or extra artwork downloads.

Companion release to PC 1.24.0, which also fixes accumulation of old installed update files. Android retains its existing package and signing identity; install over the current version to keep your music and settings.

Validation: 436 JavaScript tests, 131 native JVM tests, both ABI builds, Android lint (zero errors, nine existing warnings), final packaged asset checks and isolated phone layout/action checks. Physical-device playback, battery use and installation have not been retested.
