# Resonance Android 0.26.2-preview

Synapse has a much larger connected volume, independent regional movement, stronger frequency-driven motion and musical colors, subtle bass bursts and routed currents. Separate floating particles surround the web. The foreground and middle stay sharp, with blur further in the distance. Phone particle budgets and mobile performance defaults are preserved.

Android already makes each completed playlist song available during an active download batch. This release preserves that behavior and adds a native regression check; the matching Windows release fixes its delayed library refresh.

Approved promotion of 0.26.2-dev.6, with unchanged application behavior. VersionCode 113 exceeds all previously distributed builds. The ARM64 APK retains package ID music.resonance.mobile and the existing signing certificate. Install over the existing app; do not uninstall. Music and settings remain. Ordinary installations receive the update through Settings → App updates, followed by Android's installation confirmation. Development installations stay on their own channel and must install this APK manually to switch.

Verification: 575 shared tests, 152 Android JVM tests, both ABI builds, device-test compilation and lint (0 errors; 9 existing warnings), extracted nested startup graphs, signing identity, legacy/current update selection, uploaded size and SHA-256 digest, anonymous download access and the live Android download button. Browser-based visual checks are simulations; physical Android testing remains outstanding.
