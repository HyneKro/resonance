# Resonance Android 0.23.4-preview

- Dynamic Lyrics now fills sung words smoothly from left to right when real word start/end times are available. Line-only lyrics stay unfilled.
- The Lyrics button, existing lyric lookup and saved lyrics remain. Lyrics timing keeps manual offsets and import/export, without the experimental audio-analysis workflow.
- Highlights follow pause, seek and visual-sync delay. The animation frame loop stops while hidden or paused.

Validated with ARM64/x86_64 builds, native unit tests, Android lint, packaged web module checks and phone-sized browser interface checks. No physical Android device was available for this release. Install over the existing app to retain your library and settings.
