# Afterglow: luminous pixel synthwave

Development test builds: Windows **1.26.0-dev.31** and Android **0.26.0-dev.31** (versionCode 97). Open **Visuals → Style → Afterglow**.

- Much brighter neon road edges, terrain contours, skyline lights and sunset, with two smooth bloom passes and colour-preserving highlights. The sun's central bloom is restrained enough to retain its striped cuts while its halo spreads outward.
- Replaced the old procedural palm fragments with four original feathered silhouettes on lightweight 2D billboards. Curved trunks, separated leaflets, music-coloured gradients, trunk rings and illuminated edges give them more shape. Phone silhouettes use a smaller atlas generated locally at startup.
- Expanded the skyline to four independently moving layers with varied roofs, towers, antennas, facade divisions, cornices and pixel signs. Window occupancy fades slowly between lit/unlit states. A spectral ribbon moves vertically through window rows across the city.
- Added arcade road chevrons, shoulder pixels, broken reflections, terrain pixels and cross-shaped stars. Brighter square/cross motes respond to frequency lights, texture and percussion, leaving short pixel wind trails. Orbiting dust still controls their amount; phone trail counts remain bounded.
- Increased CRT definition with animated scanlines, a slowly rolling beam, stronger phosphor texture, grain and music-sensitive colour separation. Set **CRT scanlines** and **Phosphor dots** to zero for the clean image. **Music colours**, **Bloom** and **Glow radius** remain adjustable.
- Curved the mirrored terrain into an open bowl, compressing foreground crests and fanning them outward so more of the skyline and distant musical echoes remain visible. The forward camera and existing audio/history behaviour are preserved.

Verification: **549 shared tests**, **134 Android JVM tests**, both ABI builds and Android lint passed (zero errors, nine existing warnings). All eight visualizers passed GPU checks, independent musical-role checks and graphics-context recovery. Afterglow's focused audit checks real bloom contribution, slowly changing/frequency-lit windows, reactive particle trails, independently animated CRT with a complete zero-setting bypass, mirrored geometry, history, fixed camera, pause, track changes and phone output. Under maximum spectrum/movement, its terrain shader retains mirrored distant crests while compressing foreground heights. Desktop and phone previews were inspected, including a heavy-bass scene. Both extracted startup module graphs pass, including the new palm module; shared visual sources match both distributables byte-for-byte. A clean Windows installation reaches its empty-library welcome screen in approximately 10.8 seconds. Android retains package `music.resonance.mobile` and the existing signing certificate. No physical Android device testing was available; browser previews do not establish device performance.

Update an existing development installation through **Settings → App updates → Check for updates**. Windows applies the update when you choose to restart. Android updates the existing app with system confirmation; do not uninstall. A first development installation requires the one-time development ZIP/APK installation. Ordinary releases and the live download buttons remain unchanged.
