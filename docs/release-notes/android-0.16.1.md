# Resonance Android 0.16.1-preview

Removed the wide-legged two-step dance from Sona and all 29 other mascot appearances. The remaining seven dances keep their existing pace and three complete loops before changing. Mascots now begin with the gentler side sway.

Install over your existing app; the package ID and signing identity are unchanged (versionCode 42).

Validation: 357 shared/desktop checks and 111 Android unit tests passed. Android builds and lint completed with no errors and nine existing warnings. The extracted APK passed the recursive startup asset checks. All 30 mascot appearances were checked in the shared motion controller and browser renderer. This release has not been tested on a physical phone.
