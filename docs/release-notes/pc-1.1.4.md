Resonance now checks and downloads app updates directly from public GitHub Releases. No account is required.

- Settings & library → App updates includes automatic checks/downloads, progress, cancellation, release notes and a Restart & update action.
- Downloads are verified before installation. Music, playlists and settings stay in place; replacement failures restore the previous app files.
- Updates wait for you to restart. Music is not interrupted by an automatic installation.
- Manual ZIP updates remain available. If you are on 1.1.3 or earlier, use Install a portable update once with this ZIP to gain online updates.

175 automated tests pass, including release selection, pagination, damaged/incomplete downloads, cancellation, cached updates, preferences and portable installation/rollback.
