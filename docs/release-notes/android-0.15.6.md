# Resonance Android 0.15.6 preview

Library review now shows each title above its artist and review notes, all left-aligned. Long titles and names wrap inside the row so the menu stays readable without horizontal scrolling.

Validation: Android build, local JVM tests, lint and packaged startup dependency checks. The source-rendered review layout was checked at 412 px and 360 px phone widths, including long unbroken titles and Japanese text. No physical Android device was available for this release.

Install over the existing app to preserve your music and settings. The package ID and signing certificate are unchanged; versionCode is 39.
