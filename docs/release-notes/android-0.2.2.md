# Resonance Android 0.2.2-preview

Track Character commits the cached song profile and visual identity together. A delayed lookup retains the outgoing character instead of flashing through a temporary shape. Artwork and metadata refreshes no longer restart or randomize the current song's character. New analysis smoothly adds energy and texture; the opening silhouette stays stable until a chapter change. Seeking retains the settled-chapter transition.

Includes the 0.2.1 per-track loudness behavior and silence markers. Native playback, background controls and Android updates are unchanged.

Install over the existing app to retain downloaded music and settings. Package ID and signing certificate are preserved; versionCode is 17.

Validation: shared source regressions, rendered transition checks, Android JVM tests, build and lint, plus the startup module graph from the actual APK. No physical S22+ was connected for this release; on-device playback and graphics still need confirmation.
