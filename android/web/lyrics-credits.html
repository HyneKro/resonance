Lyrics tool credits

Catalogue lyrics and timestamps are supplied by LRCLIB when a recording matches. User imports support LRC and the Lyricsfile format.

Structured lyric files are parsed with js-yaml 5.5.0. MIT license.

The optional Windows analysis download uses whisper.cpp (b5454, CPU x64) and the multilingual Whisper small-q5_1 model. Recognition and estimated word timings run locally. They can be inaccurate for singing, overlapping voices and dense mixes; every result requires review before saving.

whisper.cpp MIT license · Whisper model MIT license

Android does not download or run these recognition models. It reads saved or imported timing and performs lightweight text highlighting.
